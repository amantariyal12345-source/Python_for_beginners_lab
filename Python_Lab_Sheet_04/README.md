# Python Programming Lab — Lab Sheet 04
## List and Dictionary Operations

This repository contains separate Python source files for all 30 questions in MCA I Semester Lab Sheet 04.

## Programs
- `Q1_sum_average_list.py` — Find the sum and average of elements in a list.
- `Q2_rotate_list.py` — Rotate a list by n positions.
- `Q3_remove_negative_numbers.py` — Remove all negative numbers from a list.
- `Q4_product_list_elements.py` — Find the product of all elements in a list.
- `Q5_squares_1_to_n.py` — Create a list of squares of numbers from 1 to n.
- `Q6_split_list_halves.py` — Split a list into two halves.
- `Q7_check_sorted_list.py` — Check if a list is sorted or not.
- `Q8_pairs_given_sum.py` — Find pairs of numbers in a list whose sum is equal to a given number.
- `Q9_flatten_nested_list.py` — Flatten a nested list.
- `Q10_list_to_string_without_join.py` — Convert a list into a string without using join().
- `Q11_student_names_marks.py` — Create a dictionary of student names and marks and display it.
- `Q12_max_min_dictionary_marks.py` — Find the maximum and minimum marks from a dictionary.
- `Q13_character_frequency_dictionary.py` — Count the frequency of characters in a string using a dictionary.
- `Q14_merge_dictionaries.py` — Merge two dictionaries into one.
- `Q15_sort_dictionary_by_keys.py` — Sort a dictionary by keys.
- `Q16_sort_dictionary_by_values.py` — Sort a dictionary by values.
- `Q17_update_dictionary_value.py` — Update the value of a key in a dictionary.
- `Q18_remove_dictionary_key.py` — Remove a key from a dictionary.
- `Q19_check_dictionary_key.py` — Check if a key exists in a dictionary.
- `Q20_sum_dictionary_values.py` — Find the sum of all values in a dictionary.
- `Q21_key_with_maximum_value.py` — Find the key with the maximum value in a dictionary.
- `Q22_numbers_and_squares_dictionary.py` — Create a dictionary with numbers as keys and their squares as values.
- `Q23_two_lists_to_dictionary.py` — Convert two lists into a dictionary.
- `Q24_invert_dictionary.py` — Invert a dictionary (keys become values and values become keys).
- `Q25_word_frequency_paragraph.py` — Count word frequency in a paragraph using a dictionary.
- `Q26_check_equal_dictionaries.py` — Check if two dictionaries are equal.
- `Q27_remove_duplicate_dictionary_values.py` — Remove duplicate values from a dictionary.
- `Q28_nested_student_dictionary.py` — Create a nested dictionary for student details (Name, Roll, Marks).
- `Q29_common_dictionary_keys.py` — Find common keys between two dictionaries.
- `Q30_string_character_frequency_dictionary.py` — Create a dictionary from a string with characters as keys and frequency as values.

## How to run
1. Install Python 3.
2. Extract this ZIP archive.
3. Open a terminal or command prompt in this folder.
4. Run an individual program, for example:
   ```bash
   python Q1_sum_average_list.py
   ```
5. Enter the requested values when prompted.

Most programs use `input()` to receive data dynamically. For list questions, enter values separated by spaces unless the program requests a nested list.
