# Lab Sheet 04 — Brief Implementation Report

**Subject:** Python Programming Lab — List and Dictionary Operations  
**Course:** MCA I Semester (Session 2026–2027)

## Objective
To practice list operations such as searching, sorting, and manipulation, and dictionary operations for storing, retrieving, updating, and analyzing data.

## Implementation
The lab sheet contains 30 separate Python programs. Questions 1–10 cover list operations, including sum and average, rotation, removing negative values, products, squares, splitting, checking sorted order, finding pairs, flattening a nested list, and converting a list to a string. Questions 11–30 cover dictionaries, including student marks, frequency analysis, merging, sorting, updating and removing keys, sums, inversion, word counts, nested student records, and common keys.

Each program is saved in an individual `.py` file named with its question number and a descriptive topic. Programs request input dynamically where applicable and display results in a clear format.

## Execution
Run each file separately using Python 3. For example:
```bash
python Q1_sum_average_list.py
```
Provide the requested input and test with multiple cases. For Question 9, enter a simple nested list such as `[[1, 2], [3, 4]]`; only use trusted input because the example uses `eval()`.

## Conclusion
These programs provide practice with Python lists, dictionaries, loops, conditional statements, input handling, and basic data processing.
