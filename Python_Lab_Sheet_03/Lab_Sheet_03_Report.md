# Lab Sheet 03 — Brief Implementation Report

**Subject:** Python Programming Lab — String and List Operations  
**Course:** MCA I Semester (Session 2026–2027)

## Objective
To practice Python string manipulation and list operations using input, loops, conditions, and basic collection handling.

## Implementation
The lab sheet contains 30 programs. Questions 1–20 cover string operations such as palindrome checking, character counting, case conversion, substring handling, frequency counting, and string rotation. Questions 21–30 cover list operations such as finding minimum/maximum values, sorting, removing duplicates, reversing, merging, finding common/different elements, and separating even and odd numbers.

Each question is saved in its own `.py` file named with the question number and a descriptive topic. The programs request input using `input()` and print clear results. Some Python methods are used where appropriate, while sorting, reversing, and frequency tasks use loops where practical.

## Execution
Run each file separately using Python 3. Example:
```bash
python Q1_palindrome.py
```
Enter test input when prompted and compare the displayed output with the expected result for that input.

## Conclusion
The programs provide practice with string traversal, loops, conditional statements, list processing, and user input in Python.
