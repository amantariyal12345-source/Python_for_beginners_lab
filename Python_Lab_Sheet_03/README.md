# Python Programming Lab — Lab Sheet 03
## String and List Operations

This repository contains separate Python source files for all 30 questions in MCA I Semester Lab Sheet 03.

## Programs
- `Q1_palindrome.py` — Check if a string is a palindrome.
- `Q2_vowels_consonants.py` — Count vowels and consonants in a string.
- `Q3_spaces_to_underscores.py` — Replace all spaces in a string with underscores.
- `Q4_uppercase_characters.py` — Extract all uppercase characters from a string.
- `Q5_remove_duplicate_characters.py` — Remove duplicate characters from a string.
- `Q6_character_frequency.py` — Find the frequency of each character in a string.
- `Q7_reverse_without_slicing.py` — Reverse a string without using slicing.
- `Q8_title_case_without_builtins.py` — Convert a string into title case without using built-in title-case functions.
- `Q9_word_count.py` — Count the number of words in a string.
- `Q10_longest_word.py` — Find the longest word in a string.
- `Q11_anagrams.py` — Check if two strings are anagrams of each other.
- `Q12_substring_check.py` — Check if a substring exists in a given string.
- `Q13_vowels_upper_consonants_lower.py` — Convert vowels to uppercase and consonants to lowercase.
- `Q14_remove_punctuation.py` — Remove all punctuation from a string.
- `Q15_first_non_repeated_character.py` — Find the first non-repeated character in a string.
- `Q16_count_digits_alphabets_special.py` — Count digits, alphabets, and special characters in a string.
- `Q17_all_substrings.py` — Print all substrings of a string.
- `Q18_sort_string_characters.py` — Sort the characters of a string alphabetically.
- `Q19_most_repeated_word.py` — Find the most repeated word in a string.
- `Q20_string_rotations.py` — Check if two strings are rotations of each other.
- `Q21_largest_smallest_list.py` — Find the largest and smallest elements in a list.
- `Q22_sort_list_ascending_descending.py` — Sort a list of integers in ascending and descending order.
- `Q23_remove_duplicate_list_elements.py` — Remove duplicate elements from a list.
- `Q24_reverse_list_without_builtin.py` — Reverse a list without using built-in reverse functions.
- `Q25_list_element_frequency.py` — Count the frequency of each element in a list.
- `Q26_merge_two_lists.py` — Merge two lists into one.
- `Q27_second_largest_number.py` — Find the second largest number in a list.
- `Q28_common_elements.py` — Find common elements in two lists.
- `Q29_list_difference.py` — Find the difference between two lists (items in the first list that are not in the second).
- `Q30_separate_even_odd.py` — Separate even and odd numbers from a list.

## How to run
1. Install Python 3.
2. Open a terminal or command prompt in this folder.
3. Run a program, for example:
   ```bash
   python Q1_palindrome.py
   ```
4. Enter the requested input when prompted.

Each program accepts input dynamically and includes comments where useful. For list questions that request integers, enter numbers separated by spaces, for example `4 8 1 6`.
