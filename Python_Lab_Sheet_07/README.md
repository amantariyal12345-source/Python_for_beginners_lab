# Python Programming Lab Sheet 7 — File Handling

This folder contains one Python source file for each of the 30 questions in the uploaded Lab Sheet-07 PDF.

## How to run
1. Install Python 3.
2. Extract this folder.
3. Open a terminal/command prompt in this folder.
4. Run a program, for example:
   ```bash
   python 01_create_write_file.py
   ```

## Notes
- Each `.py` file begins with the corresponding question.
- Programs include comments and use relative file paths.
- Text-file examples commonly use `sample.txt`; create it by running `01_create_write_file.py` first.
- The number-sum program expects `numbers.txt` with one number per line.
- The CSV examples use `students.csv`; create it by running `21_create_write_csv.py` first.
- The merge-text-files program expects `first.txt` and `second.txt`.
- The combine-CSV program expects `students.csv` and optionally `students_extra.csv`.
- Run each program separately. Some programs modify or create files in this folder.
