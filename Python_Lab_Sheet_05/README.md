# Python Programming Lab Sheet 05 — Tuples Operations

This repository folder contains 30 separate Python programs, one for each question in the supplied MCA I Semester lab sheet.

## Files
- `Q1_tuple_program.py` through `Q30_tuple_program.py`
- Each file starts with its question as a comment/docstring and includes the Python code.

## Run a program
Open a terminal in this folder and run, for example:
```bash
python Q1_tuple_program.py
```
On some systems, use `python3` instead of `python`.

The programs use basic Python tuple operations and standard built-in functions. Some programs use fixed sample tuples, while input-based questions prompt the user.
