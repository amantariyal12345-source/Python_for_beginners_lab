# Python Programming Lab – Lab Sheet 06 (Set Operations)

This folder contains 30 separate Python 3 programs, one for each question in Lab Sheet-06.

## Files
- `Q01_create_display_set.py` through `Q30_all_basic_set_operations.py`
- Each file begins with the question and includes comments explaining the logic.

## How to run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run an individual program, for example:

```bash
python Q01_create_display_set.py
```

4. Enter the requested values when prompted.

## Notes
- Set elements are unordered, so their printed order may vary.
- Most programs accept space-separated input.
- Q27 uses a set to compare distinct characters and frequency dictionaries to correctly account for repeated characters; sets alone cannot distinguish strings such as `aab` and `abb`.
- Q23 converts the set back to a list, as required by the task of removing duplicates from a list. The original order is not guaranteed.
